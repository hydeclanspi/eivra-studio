# Eivra Demo 导览

2026-10-27 更新。基于两份 v1 方案、c27 草图、Lucent 光效附录及用户最新反馈实现。主讲形象已由 Facet「棱」改为珠白小鲸鱼；保留中文字幕、自动避让停靠与克制光效。语音与外部完成率统计未启用。

## 体验

- 每次进入 Demo 首页：文档、字体、图片解码、首页完整校准和布局就绪后，再留出 3.75 秒阅读时间出现欢迎窗。资源未就绪时持续等待；计时期间新图片、字体加载、布局变化、后台隐藏或超过 250ms 的帧间隔会重新计时。欢迎窗有 4 秒倒计时，悬停、聚焦按钮或页面隐藏时停表。
- `?tour=1` / `?tour=dev`：等首屏就绪后自动播放；`?tour=short`：速览；`?tour=0`：当前 URL 禁用，移除参数后恢复，旧会话标记不再拦截。
- 桌面完整轨 33 步，剧本预算 190.52 秒；速览 21 步，预算 131.34 秒。每次换页留出 3 秒（History 与球队档案 2 秒）无暗场遮挡的页面总览，再定位讲解。实际时间受页面计算、资源加载与设备速度影响，不伪造固定完成时间。
- 玻璃主讲窗在同一个 DOM 元素内切换种子、主讲、胶囊、舞台形态。主讲窗可暂停和退出，暂停胶囊增加「从头开始」；没有音轨，因此不放无效的声音按钮。
- 点击遮罩、滚轮、Space 或切到后台会暂停。暂停后页面完全可操作；继续时重新定位当前区域并保留剩余停留时间。Esc 立即退出；← / → 可快退快进。时间轨支持鼠标／触控拖动和方向键、Home／End，松开后从对应片段开头重建界面并继续播放；拖动期间取消原动作并冻结时钟。
- 完整轨包含投前判断、投后导入、组合、结算、Dashboard 总览／深度分析／数据总览／周期战报、Quants、History／球队档案、Console，再回到 New 引出结尾。两条轨都演示一张两场组合的投后解析、依赖风险单元格详情与下方证据、组合包容错矩阵编辑／撤销／释放约束，以及真正重新求解的定制结果。Dashboard 总览向下展示趋势；完整轨还深入优势、联赛、近因机制和风险指标。
- 比分概率云之后展示该标的过往记录，各球队列表滚到已有投后复盘备注（无投后备注时定位投前备注）；读取真实演示账本，不编造备注。投后导入解析后继续下翻，核对已填入的比赛、投注项和赔率。回拖到任一新增片段都能恢复所需表单状态，连续播放复用刚才的解析结果。
- 顶栏「导览」从当前页面的第一个片段开始，并沿原时间轨继续；手机优先速览，若速览缺少当前页面（Settle、深度分析、指标总览、球队档案），改用完整轨的对应片段。首页仍从判断开始；暂停窗「从头开始」与结尾「重播」从轨道开头播放。新开导览、全程重播、完成与退出都会清理导览输入和求解结果；普通「继续」保留当前进度。
- Quants 位于 Dashboard 之后、History 之前，两条轨均依次介绍实验工作室（页面「实验工作台」）、策略库、数据中心，实际切换标签并框选相应内容。Quants 字幕比其他章节小 1px（桌面 13px、手机 12.5px）。只切换视图，不创建研究或运行实验；「打开完整指南」暂停播放，关闭指南后继续。Console 先展示拟合，再连续下滑到页面底部，然后清理临时演示状态、回到 New 投前页，停留后引出结尾。暂停、跳转会取消原动作。
- 完成/关闭记录保留，但不再阻止欢迎窗。刷新首页或从其他页返回首页都会重新计时；在当前首页关闭后不会立即再弹，导览内部回到首页也不会打断播放。刷新其他页面的中途记录仍以暂停态恢复。手机有始终可达的顶栏导览入口和底部主讲窗。

开场以珠白鲸鱼、五节点闭环和三个能力预览组成，与结尾呼应。演示备注为「利物浦连续三年在主队主场不胜」「维尔茨意外红牌」；当前演示战报呈现为「(S3) 26-27 欧冠淘汰赛阶段」。S3 为样例战役展示编号，不改变真实账本周期或指标口径。

深度分析的「最优组合发现」在 TOP 数量左侧显示绿色「仅为数据模拟，无足够样本」胶囊，复用顶栏 preview 材质，仅在演示态出现。

历史标题右侧在 preview 下显示「beta 测试数据」，复用顶栏 Live 胶囊的材质与圆点，作为不可点击的状态标识。金额样例以两位数亏损、少量百元亏损和大小不同的盈利组成；胜单返还等于投入乘总赔率，负单亏损仅为投入。总赔率与分腿赔率、周期结算与账本盈亏均对齐；比赛、赛果和待结算样例保留。金额数据和标记均限于 demo，不修改真实用户账本。

## 实现边界

`tourReady` 以真实绘制帧检查页面就绪。首页通过 `data-tour-ready` 明确报告 idle 阶段的完整校准是否完成；已存在的非懒加载图片和进入视口的懒加载图片需完成加载／解码，失败图片视为已结束。屏外懒加载、持续 CSS 动画、云同步与后台采集不属于首页就绪条件；没有通用的“未来不再增加任何元素”信号。新资源或布局变化重开阅读窗口，手动开始、切页、卸载或进入 Full 模式会取消等待。

`TourProvider` 在 BrowserRouter 内、App 外，不受页面 pathname 重挂载影响。`tourScript` 集中文案、动作与轨道；`tourMachine` 是纯 reducer；`tourBus` 负责注册、超时、AbortSignal 和幂等页面动作。

New 调用真实本地解析；明确的编号段落逐单解析，保持金额隔离，普通文本仍按原多场输入处理。Portfolio 调用原求解器、蒙特卡洛与原揭晓动画。导览不提交投资、不结算、不改模型参数。静默求解不弹 alert，也不追加计划历史。矩阵重算的有限候选池保留原有组合，避免仅因截取候选而丢失原本可行的解；定制结果仍经过原约束验证与求解流程。解析表单和求解结果只缓存于导览内存，导览进行中跨路由保留，刷新重建。暂停后编辑这些示范字段也属于临时演示；重播／完成／退出时清理。`tourBus.reset()` 同时清理未挂载页面的缓存和已挂载页面的状态。原有访客草稿始终保留，清理时恢复，避免把示范输入写入持久草稿。解锁时停止导览并清空导览缓存，New 恢复持久草稿，Portfolio 移除导览生成的展示结果。

`data-tour` 是稳定锚点；定位先等实际滚动／布局稳定，播放中逐帧重新解析目标和视口坐标，替换节点、展开动画和滚动都不会复用旧矩形。只在几何或数据签发生变化时渲染；目标离屏时移除高亮，框选不再对坐标做延迟缓动。`data-tour-tag` 直接使用各页面已有派生值。拟合计算未就绪时显示 `UNAVAILABLE / COMPUTING`，后续属性变化会刷新标签。不要把 v1 文稿中的 86.3%、112、20、0.82、181 等例子写死为计算结果。

`demoChoreography` 协调 Quick Input 展卷、DemoBubble、ComboExpandHint 和 AdaptiveLoop coach。导览在场时禁用旧提示，取消欢迎后从关闭时重新计时，完成后将旧提示记为本会话已展示。组合揭晓后的额外展卷也在导览期间暂停。

组合页的五档风险偏好回测在展开面板后才计算，避免隐藏面板在开场重复运行求解器。深度分析通过真实标签切换进入联赛与时间近因内容；回拖到策略段时恢复对应标签。

历史匹配只在投后导入、对应球队输入处于焦点且导览不在场时出现。匹配列表在输入区下方占据正常文档流；失焦、切页、解析、Esc 或关闭会收起。投前使用本来就有的球队过往记录区，不再显示旧浮层。取消旧的 120ms 延迟失焦回调，避免主客队快速切换时误清新焦点。

## 光效与布局

`lightRenderer.js` 移植 Lucent `3789a00` 的分层蓝白光、flare、扫描、斜向光幕、香槟虚线与激光。排班保留截断正态 N(0.70, 0.10²)、73/20/7% 波次、不放回抽车道、方向概率、275ms 开场和 1.53–3.17s 波间隔。

`laneRouting.js` 从可见外层卡片的真实矩形取至少 12px 的空隙，排除穿过其他卡片的通道；链接路径最多三次转弯，找不到通路或手机单列时回退直线。像素比最多 2；无光效时清空画布并停止 rAF。暗场不用背景模糊，玻璃只在主讲窗和数据签上。

产品全局 `html { zoom: .9 }` 会影响 fixed 元素坐标。Portal 反向校正 zoom，使 DOMRect、指针与光层都使用视口像素；滚动距离转换回容器坐标。改动全局缩放时必须重新验证这条边界。

减弱动效保留自动内容节奏，关闭打字、激光、光幕与持续动画。深色旗舰主题使用深色玻璃和加色混合。字幕的无障碍文本整句更新，装饰层 aria-hidden，退出后恢复焦点。

小鲸鱼的轮廓参考来自 [DeepSeek 官方鲸鱼图形](https://github.com/deepseek-ai/DeepSeek-LLM/blob/main/images/logo.svg)，实现为独立绘制的 SVG，使用 Eivra Logo 的珠白、香槟金细边、菱形核心与淡蓝折光。包括游动、眨眼、思考气泡和完成动作；[独立形象预览](design/eivra-whale-host.html) 可直接本地打开。

组合明细使用上下两层网格：球队标签在上、指标在下。层级代码转为可读名称与计数，长队名和指标允许换行，避免固定 236px 指标区挤压队名。

原始独立草图保存在 [eivra-demo-tour-study.html](design/eivra-demo-tour-study.html)，与根目录用户提供的 c27 文件逐字一致。

## 验证与回归

运行 `npm run lint`、`npm test`、`npm run build`。`src/lib/__tests__/tour.test.js` 覆盖状态转换、暂停时钟、存储失败、资格排除、动作取消/超时、当前页面起播与手机轨道回退、锚点与路由漂移、剧本时长、车道避障和激光排班。`tourReady.test.js` 另覆盖超 15 秒慢加载、完整校准、图片解码与换源、失败／懒加载图片、布局／字体变化、隐藏／卡顿和取消。

`scripts/check-demo-tour.mjs` 在已有 Playwright 环境中运行完整轨或短轨，检查真实输出、所有步骤、完成态和存储隔离；也可通过 `TOUR_BASE_URL` 验证对应线上部署。

空浏览器中途解锁测试暴露了已有的 genesis 重入问题：`writeJSON` 同步触发 data-changed，挂载的页面 getter 再次初始化数据。`localData.js` 现在用仅在事务执行期间生效的 guard 阻止重入；失败不会提前写完成标记，并有独立回归测试。

浏览器验收结果记录在 [首版验证记录](audits/2026-10-23-demo-tour.md)、[首轮修订](audits/2026-10-24-demo-tour-refinement.md)、[深入演示与回拖验证](audits/2026-10-25-demo-tour-deep-dive.md) 和 [就绪触发与三工作区验证](audits/2026-10-27-demo-readiness-workspaces.md)。本地构建和浏览器通过不等于 CI 或线上发布完成，后两项需按对应提交检查。
