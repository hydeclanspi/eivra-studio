# Eivra Demo 导览

2026-10-23。基于两份 v1 方案、新版 UI 修订、c27 草图及 Lucent 光效附录实现。PDF 对话中没有追加最终选型，第一版采用方案推荐值：Facet「棱」、眼神开启、中文字幕、右下停靠、克制光效。语音与外部完成率统计未启用。

## 体验

- Demo 首页首访：渲染后 600ms 出现欢迎窗，4 秒倒计时；悬停、聚焦按钮或页面隐藏时停表。
- `?tour=1` / `?tour=dev`：直接播放；`?tour=short`：速览；`?tour=0`：本次标签页会话禁用，包括之后的页面导航。
- 桌面完整轨 11 步，剧本预算 56.95 秒；速览 5 步，预算 30.45 秒。实际时间受页面计算、资源加载与设备速度影响，不伪造固定完成时间。
- 玻璃主讲窗在同一个 DOM 元素内切换种子、主讲、胶囊、舞台形态。主讲窗只有暂停和退出；首版没有可用音轨，因此不放无效的声音按钮。
- 点击遮罩、滚轮、Space 或切到后台会暂停。暂停后页面完全可操作；继续时重新定位当前区域并保留剩余停留时间。Esc 立即退出；← / → 可快退快进。
- Quants 的「打开完整指南」暂停播放，关闭指南后继续。
- 完成/关闭会记忆；刷新中途记录以暂停态恢复。手机有始终可达的顶栏导览入口和底部主讲窗。

## 实现边界

`TourProvider` 在 BrowserRouter 内、App 外，不受页面 pathname 重挂载影响。`tourScript` 集中文案、动作与轨道；`tourMachine` 是纯 reducer；`tourBus` 负责注册、超时、AbortSignal 和幂等页面动作。

New 调用真实本地解析；Portfolio 调用原求解器、蒙特卡洛与原揭晓动画。导览不提交投资、不结算、不改模型参数。静默求解不弹 alert，也不追加计划历史。解析表单和求解结果只缓存于导览内存，跨路由可继续查看，刷新重建；原有访客草稿保留，真实编辑后才恢复正常草稿写入。解锁时停止导览并清空导览缓存，New 恢复持久草稿，Portfolio 移除导览生成的展示结果。

`data-tour` 是稳定锚点；`data-tour-tag` 直接使用各页面已有派生值。拟合计算未就绪时显示 `UNAVAILABLE / COMPUTING`，后续属性变化会刷新标签。不要把 v1 文稿中的 86.3%、112、20、0.82、181 等例子写死为计算结果。

`demoChoreography` 协调 Quick Input 展卷、DemoBubble、ComboExpandHint 和 AdaptiveLoop coach。导览在场时禁用旧提示，取消欢迎后从关闭时重新计时，完成后将旧提示记为本会话已展示。组合揭晓后的额外展卷也在导览期间暂停。

## 光效与布局

`lightRenderer.js` 移植 Lucent `3789a00` 的分层蓝白光、flare、扫描、斜向光幕、香槟虚线与激光。排班保留截断正态 N(0.70, 0.10²)、73/20/7% 波次、不放回抽车道、方向概率、275ms 开场和 1.53–3.17s 波间隔。

`laneRouting.js` 从可见外层卡片的真实矩形取至少 12px 的空隙，排除穿过其他卡片的通道；链接路径最多三次转弯，找不到通路或手机单列时回退直线。像素比最多 2；无光效时清空画布并停止 rAF。暗场不用背景模糊，玻璃只在主讲窗和数据签上。

产品全局 `html { zoom: .9 }` 会影响 fixed 元素坐标。Portal 反向校正 zoom，使 DOMRect、指针与光层都使用视口像素；滚动距离转换回容器坐标。改动全局缩放时必须重新验证这条边界。

减弱动效保留自动内容节奏，关闭打字、激光、光幕与持续动画。深色旗舰主题使用深色玻璃和加色混合。字幕的无障碍文本整句更新，装饰层 aria-hidden，退出后恢复焦点。

原始独立草图保存在 [eivra-demo-tour-study.html](design/eivra-demo-tour-study.html)，与根目录用户提供的 c27 文件逐字一致。

## 验证与回归

运行 `npm run lint`、`npm test`、`npm run build`。`src/lib/__tests__/tour.test.js` 覆盖状态转换、暂停时钟、存储失败、资格排除、动作取消/超时、锚点与路由漂移、剧本时长、车道避障和激光排班。

`scripts/check-demo-tour.mjs` 在已有 Playwright 环境中运行完整轨或短轨，检查真实输出、所有步骤、完成态和存储隔离；也可通过 `TOUR_BASE_URL` 验证对应线上部署。

空浏览器中途解锁测试暴露了已有的 genesis 重入问题：`writeJSON` 同步触发 data-changed，挂载的页面 getter 再次初始化数据。`localData.js` 现在用仅在事务执行期间生效的 guard 阻止重入；失败不会提前写完成标记，并有独立回归测试。

浏览器验收结果记录在 [本轮验证记录](audits/2026-10-23-demo-tour.md)。本地构建和浏览器通过不等于 CI 或线上发布完成，后两项需按对应提交检查。
