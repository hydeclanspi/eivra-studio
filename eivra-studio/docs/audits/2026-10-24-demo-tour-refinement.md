# Demo 导览第二轮修订验收 · 2026-10-24

## 改动

- New 初次进入后至少等 8.5 秒再出现导览；资源仍在加载时适当延长。手动启动会取消尚未触发的自动欢迎。
- 跨路由先展示完整页面，5 秒后才聚焦讲解。等待从无暗场的页面完成绘制后开始，避免 React 路由重渲染和慢帧占用浏览时间。
- 新增投后导入、Dashboard 总览／深度分析／数据总览，以及 History／球队档案。完整轨 17 步、预算 131.4 秒；短轨 8 步、预算 67.2 秒。预算不包含初访等待、欢迎倒计时和额外计算耗时。
- 暂停胶囊增加「从头开始」。重播、结束、退出时清理已挂载页面的表单／结果和未挂载页面的缓存。导览中编辑的示范字段仍只保留于内存；原有持久草稿保留。
- 原 Facet 主讲形象改为独立绘制的珠白小鲸鱼，采用金色细边、菱形核心和淡蓝折光。四种动作见 [独立预览](../design/eivra-whale-host.html)。
- Portfolio 明细中球队与指标改为上下两层网格，移除固定指标宽度；内部 `tier_2/...` 转换为可读层级名称和数量。
- 历史对阵匹配不再覆盖投前页面。投后仅对应球队输入有焦点时显示，放在输入区下方的正常文档流中；外部点击、Esc、关闭、换视图、解析和导览开始均会收起。取消 120ms 延迟失焦回调，避免主客输入快速切换时清掉新焦点。

跨页验收使用浏览器 MutationObserver 记录真实 DOM 阶段，检查每个新路由均进入无暗场的总览，再经过至少 4.9 秒（观测容差）进入聚焦阶段。初测发现仅等待路由函数返回会让页面绘制吃掉数百毫秒，已通过等待真实绘制后重新计时修复。

可复现浏览器检查（使用已有 Playwright，不添加产品依赖）：

```sh
node scripts/check-demo-tour.mjs
TOUR_TRACK=short TOUR_WIDTH=390 node scripts/check-demo-tour.mjs
node scripts/check-history-matching.mjs
```

可配置 `PLAYWRIGHT_MODULE`、`BROWSER_EXECUTABLE` 和 `TOUR_BASE_URL`。浏览器测试在独立临时上下文中运行。本轮为本机 headless Chrome／Edge 和手机尺寸视口验证，未声称 Safari、Firefox 或真实手机设备验收。

本记录声明本地结果。发布后仍需核对对应提交的 CI、Vercel，以及正式域名上的浏览器流程。
