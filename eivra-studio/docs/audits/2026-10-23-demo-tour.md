# Demo 自动导览验收 · 2026-10-23

## 浏览器验证

在本机 Vite 环境通过 Playwright 驱动已安装的 Google Chrome 与 Microsoft Edge，均为 headless 浏览器。本表不代表 Safari、Firefox 或真实手机设备验收。

| 场景 | 实测结果 |
| --- | --- |
| Chrome，1440 × 1000，全程 11 步 | 到达完成卡，真实解析和真实求解成功，无 pageerror 或 alert |
| Chrome，390 × 844，短轨 5 步 | 到达完成卡；主讲窗在视口内；退出后跨路由查看仍有组合结果 |
| Chrome，768 × 900，玄极深色 + 减弱动效 | 装饰 canvas 隐藏；内容继续；Esc 退出有效 |
| Edge 155.0.4283.62，1280 × 900 | 原生 `html zoom: .9` 下卡片、光圈和挖孔按视口对齐，误差小于 1px；主讲窗避开目标 |
| Edge，途中缩至 1024 × 900，CPU 4× 降速 | 完成真实求解及短轨，产出 20 方案 / 50,000 次 MC；求解动作约 26 秒，不作为 30 秒时长或流畅帧率保证 |
| 首访欢迎、悬停、取消 | 悬停超过 4 秒不启动；离开后自动启动；取消后刷新不再自动弹出，入口仍在 |
| 打字途中暂停、继续 | 暂停后文本不再变化；继续完成解析 |
| 刷新恢复 | 同一步以暂停态恢复，继续后重新定位 |
| 手动接管 | 真实编辑后撤销导览缓存；跨路由恢复用户草稿；继续导览重新解析且不覆盖已保存的用户草稿 |
| 页面跳转、方向键、Quants 指南 | 暂停时页面可操作；继续返回相应导览位置；指南关闭后恢复 |
| 排除与模式切换 | `/arsenal`、设计预览、`?tour=0` 不出现导览；解锁 Full 立即移除入口和舞台；无递归异常 |
| 数据隔离 | 自动导览不写投资、组合历史或新建草稿；原草稿保留；展示缓存仅在内存 |

正常桌面完整轨实测约一分钟。声明的 56.95 / 30.45 秒是剧本预算，不包含所有加载与主线程计算延迟。低速 CPU 场景最初使用的 25 秒等待阈值不足，扩为 45 秒后看到真实求解完成；没有修改结果或提前跳过计算来通过检查。

## 可重复冒烟检查

启动开发服务，使用已安装的 Playwright 运行：

```sh
node scripts/check-demo-tour.mjs
TOUR_TRACK=short node scripts/check-demo-tour.mjs
```

脚本检查每一步到达、真实组合输出、完成状态、pageerror、alert 以及业务存储隔离。可用 `TOUR_BASE_URL` 指向部署地址，用 `PLAYWRIGHT_MODULE` 和 `BROWSER_EXECUTABLE` 指定外置运行时与浏览器；不会为产品添加 Playwright 依赖。

本记录声明的是本地验证。发布需另行核对相应提交的 GitHub Actions、Vercel 状态及线上冒烟结果，不能从本地通过推断线上完成。
