# Eivra Studio v4 · Compose Native

A Kotlin / Jetpack Compose app with Eivra's original calculation kernel. Open this directory in Android Studio. From the repo root, `cd compose-and-ark-native/v4`, `bash lanes/platform/prepare.sh`, then `bash gradlew :app:testDebugUnitTest :app:assembleDebug :app:assembleDebugAndroidTest`. Byte-verified release evidence belongs to the run for the installed commit. `docs/I03.md`, `WORKSTREAMS.md` and `briefs/` describe earlier milestones, not the current release. See [native index](../README.md).
