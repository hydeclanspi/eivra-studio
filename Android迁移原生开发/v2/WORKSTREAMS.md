## Interface (source = app/src/main/java/com/eivra/studio/v2/api/Studio.kt)

`env.ports.read(op, args)` and `env.ports.write(op, args)` are suspend, accept positional `JSONArray` and return a JSON string (object/array/scalar, no extra envelope). Errors throw; do not turn “not wired” or invalid predictions into success/zeroes. `ports.state` is a `StateFlow<WorkspaceState>`; observe `mode` + `revision`. On successful durable mutation increment revision; on failure leave it unchanged. Lane UIs must not open QuickJS, prefs or file storage for shared data. Host mode/counter come from platform, not hardcoded demo text. Read operations must be side-effect free. Tests can inject a `StudioPorts` fixture; never ship fake data as the real backend.

**First shared calls.** `read("workspace.snapshot", [])` → original exported bundle, `read("forecast.buildDraft", [matches, isoTime])` → original draft forecast; `read("naturalInputParser.parseNaturalInput", [text])` → original parse result. `write("workspace.saveInvestment", [record])` recalculates/freezes forecast and persists by stable, unique record id; returns `{id, revision}`. `write("workspace.settleInvestment", [id, form])` uses the original per-leg settlement form, returns `{id, revision}`. Do not pass demo/test IDs in production or auto-confirm a user's Conf. For post-import do not fabricate an ex-ante snapshot. `write("draft.put", [draft])` → `{id}`; `read("draft.get", [id])` → `{matches:[...], ...}`; the common payload is the canonical New draft (`home_team`, `away_team`, `entries`…), NOT the whole bundle. Strategy hands that ID to Ledger via `Dest(Route.New,id)`; no implicit investment save. If a field can't be represented, do not silently discard it. Further analytics/research methods: copy names, arguments, defaults and return shapes from the actual Web calls; document extensions + fixtures in your `docs/PORTS.md`. Platform owns allow-listed execution; no arbitrary JS strings from UI/imports. No second formula set, forecast fallback, or implicit network sync.
