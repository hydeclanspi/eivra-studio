# StudioPorts · local platform

From v2 run `bash lanes/platform/prepare.sh` before Gradle (existing CI does this). Android uses the checked-in Web modules at this revision in QuickJS, without a WebView. Methods are suspend, positional JSONArray, JSON-string return, throw on error. Observe both state.mode and revision; discard late UI results after an input or workspace change. Mode is a local namespace, not Web authentication. Default demo is a writable sandbox; owner starts with no investment history. Nothing syncs.

| call | args → result |
|---|---|
| read workspace.snapshot | `[]` → original `localData.exportDataBundle()` with version, exported_at, system_config, team_profiles, investments, access_logs. Never use array index for identity. |
| read naturalInputParser.parseNaturalInput | `[text]` → original parser object (camelCase homeTeam/awayTeam, percentage controls, diagnostics, actualInput). Parser defaults are not user-confirmed Conf. |
| read forecast.buildDraft | `[canonicalMatches, ISO-with-offset]` → profiles, combinedProfile, combinedOdds, expectedRating, recommendedInvest, poolBalance (available cash for sizing), forecastSnapshot. Synthetic match below. Ratios, not percentages. Blank odds and unconfirmed Conf are for the editor, not a priced forecast. |
| write workspace.saveInvestment | `[{id,created_at?,inputs,combo_name?,matches,...}]` → `{id,revision}`. Keep a stable ID and payload across retries. One fresh freeze inside the serialized commit, never trust a UI forecast. Supplied created_at retained; generated_at is the actual freeze clock. Per-mode, same request replays original receipt; same ID with changed data throws. |
| write workspace.importInvestment | `[record]` → `{id,revision}`. Pending historical ticket, `entry_mode:'post'`. No ex-ante snapshot or invented Conf. Never use saveInvestment as fallback. |
| write workspace.settleInvestment | `[id,{revenues:'20',matches:[{results:'2-1',isCorrect:true,matchRating:'0.6',matchRep:'',postNote:'…'}]}]` → `{id,revision}`. One outcome per match in the stored order, optional `id` cross-check. Explicit zero revenue is valid. Original Settle updater and outcome-availability timestamps. No re-settlement with changed form. |
| write draft.put / read draft.get | `[draft]` → `{id}`, `[id]` → original New draft object including unknown keys, nulls and unfinished strings. A stable draft.id updates that checkpoint. Does not change investments or pendingCount. Navigate with `Dest(Route.New,id)`. |
| write workspace.switch | `['owner'\|'demo']` → `{mode,revision}`. Explicit action only; independent files and drafts. Missing/corrupt data is not a zero-result success. |

Synthetic caller fixture: `{"home_team":"Arsenal","away_team":"Chelsea","entries":[{"name":"主胜","odds":2}],"conf":0.6,"mode":"常规-杠杆","tys_home":"M","tys_away":"M","fid":0.4,"fse_home":0.1,"fse_away":0.1}`. No production record ID is fixed in code. Use `conf:null` until confirmed (explicit `conf_confirmed:false` also blocks). Output source: `NewInvestmentPage.jsx:calculateDraftMetrics/buildInvestmentPayloadFromDraft`, `SettlePage.jsx:getValidationError/buildSettlementUpdater`, `investmentForecast.js`, `localData.js`. Page functions are extracted at build under a source digest; a changed page fails the build pending review.

Read-only originals: `analytics.getDashboardSnapshot`, `.getAnalysisSnapshot`, `.getMetricsSnapshot`, `.getReservoirState` (`[]` for default view); `.getTeamsSnapshot` (`[query, filter]`), `.getPredictionCalibrationContext` (`[{detail:'lite'}]` for New); `preMatchOpinion.weightsFromSlider([{lo,hi,center,modes}])` and `.jointScoreCells([homeWeights,awayWeights])`. No arbitrary module/function execution. Forecast, parser and analytics read paths run against a private working copy; their storage cannot commit.
