# I03: confidence selection, persistence and synchronization

I02's timed-out save is not evidence of a wrong settlement. The diagnostic build 71f0d80 / run 44420270098 showed that on the normal 390×844dp emulator, with the stake editor focused, the scroll viewport was y=72..609 and the tapped 0.6 tick was still at y=−240..−192. Stake, price and both teams had values; selected was false; editable Conf was empty. The save gate correctly rejected an unconfirmed probability. The same APK's offline engine accepted the identical, explicitly confirmed draft.

The I03 scale is not another nested scroller. Marks share one row when there is room and otherwise wrap according to a 44dp minimum column width; touch cells stay at least 48dp tall. Selecting a mark commits the explicit user value and dismisses an active editor. Empty Conf and invalid forecasts still cannot save. The end-to-end case performs a physical touch on a visible 0.6 target, asserts selected state and numeric value, freezes a unique demo ticket, settles the same ID, checks its leg on the History screen and checks the whole forecasting snapshot. A separate read-only instrumentation verifies the record from a fresh process after force-stop. The tests and diagnostics run only on the disposable emulator's demo workspace. Expanded data and frame reports are CI artifacts, never user ledgers committed to Git.

The four prior feature heads (Ledger 59c1325, Insights a4c18a9, Platform b262de0, Strategy 90d134a) were reconciled on android-native in 71f0d80. Platform files were already byte-identical; its final commit is now also a parent. Strategy added its final four tests/tools/handoff files. Production Web main and the v1 subtree have not been moved or edited. Eivra Studio I03 has a separate debug package ID (com.eivra.studio.v2.i03); it does not overwrite I01/I02 or migrate their data. Debug signing is not a stable production upgrade channel.

CI must be green for this exact integration revision. The Web reference job checks CJK availability and uses a digest-pinned OFL font if absent; it is independent of Android correctness. Two device sizes are exercised even if one fails; the overall job still fails on any assertion. Debug emulator frame timings are not evidence of 60/120 Hz on a production device. Visual and performance sign-off are separate from saving an investment.
