# 手机／平板验收矩阵

| 窗口 | 基准 | 导航 | 内容 | 必须测试 |
|---|---|---|---|---|
| 360×800 | 小屏 Android | 四个主导航＋More | 单栏；表单元件纵向 | 无横向溢出、键盘、返回、滚动 |
| 390×844 | 常见手机 | 同上 | 单栏；卡片保持原主题 | 触控、输入、结算、More 全部路由 |
| 844×390 | 手机横屏 | 宽度驱动 | 可双列的字段组 | 旋转状态保留、无遮挡 |
| 840×600 | 窗口／分屏边界 | 工作台导航 | 多栏内容 | 宽度断点、无强制拉伸 |
| 1280×800 | Android 平板横屏 | 顶部主导航＋工作区侧栏 | 桌面式工作台 | 双栏输入、图表、列表、触控 |
| 1920×1080 | 桌面窗口模拟 | 同上 | 最大内容宽度，留呼吸空间 | 不拉成长行、性能与帧时 |

## 每页验收状态

New / Portfolio / Settle / Dashboard / Analysis / Metrics / Quants / History / Teams / Console 均需验证：
- 原生渲染，无 WebView；
- loading / empty / error / populated；
- 触控、系统返回、屏幕阅读器、字体放大；
- 横竖屏与后台恢复不丢草稿、不重复结算；
- 同一份原始 bundle 在网页与 Android 的派生指标一致；
- 录屏／截图与帧时报告，不以“代码应该流畅”作为验收。

## 性能门槛（初版，真机校准后冻结）

- 主要滚动与切页 P95 帧时不超过当前刷新率帧预算；
- 不产生连续可感知卡顿，P99 单独记录；
- 重计算不阻塞主线程；加载进度可感知；
- 冷启动、切页、滚动、Dashboard 重计算分别测量；
- 内存、ANR、崩溃与后台恢复有证据。
